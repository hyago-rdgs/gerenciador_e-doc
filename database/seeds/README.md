# Seeds do core

Este diretório contém apenas dados técnicos necessários a qualquer
implementação do gerenciador e-Doc.

Execute os arquivos em ordem alfabética depois do `schema.sql`.

O seed `20260829_001_controle_acesso.sql` cadastra perfis, módulos,
permissões e os vínculos iniciais. Execute-o uma vez: os vínculos poderão ser
personalizados posteriormente pela interface do sistema.

Usuários, tipos de documento, metadados e localizações não devem ser
inventados nem extraídos de uma implementação real.
